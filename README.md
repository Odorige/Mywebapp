# ClipWave

ClipWave is a cloud-native video sharing web application developed for **COM769 – Scalable Advanced Software Solutions, Coursework 2**.

The application allows users to browse, search, watch, comment on, and rate videos. Creators can upload videos together with relevant metadata.

## Features

- User registration and login
- Creator video uploads
- Video browsing and search
- Video playback
- Comments and ratings
- Video metadata management
- PostgreSQL database
- Redis caching
- MinIO object storage
- Docker-based deployment
- FFmpeg-based video processing

## Technologies

- HTML, CSS and JavaScript
- Node.js
- Express.js
- PostgreSQL
- Redis
- MinIO
- Docker and Docker Compose
- Nginx
- FFmpeg
